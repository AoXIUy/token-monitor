# Token Monitor 0.98.2

# English

## What's changed

<!-- app-update-notes:en:start -->
### Fixed
- **Packaged App Launch (`app.asar`):** Bundled `plugins/quota-alerts/evaluator.cjs` in `package.json -> build.files`, fixing the `Cannot find module '../../plugins/quota-alerts/evaluator.cjs'` main-process startup crash in packaged Windows and Linux builds (`0.98.1`).
- **Packaged OpenClaw Skill Provisioning:** Bundled `skills/openclaw-token-monitor/**/*` in `package.json -> build.files` and updated `installOpenClawSkill` to read and write files cleanly when extracting `SKILL.md` and `scripts/query-token-monitor.mjs` from Electron `app.asar`.
- **Packaging & CI Timer Hardening:** Added an automated test verifying every relative `require()` across `src/electron`, `src/shared`, `src/hub`, and `src/mcp` is covered by `package.json -> build.files`, and stabilized debounce settlement polling in OpenClaw bridge and route tests.

### Notes
- Includes all `0.98` OpenClaw integration capabilities: real-time session completion, approval, quota, and service-incident pushes, unified `/api/query/*` & 17-tool MCP endpoints, Desktop `local`-mode support, and optional `127.0.0.1` loopback HTTP/MCP bridge.

- **打包完整性与测试稳定性加固：** 新增自动回归校验，确保 `src/electron`、`src/shared`、`src/hub`、`src/mcp` 下所有相对路径 `require()` 均被 `package.json -> build.files` 覆盖，并放宽 OpenClaw 桥接及路由测试在高并发下的防抖等待轮询。
