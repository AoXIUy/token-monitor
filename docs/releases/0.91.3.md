# Token Monitor 0.91.3

Merged upstream [`Javis603/token-monitor`](https://github.com/Javis603/token-monitor) through [`148bb9fa`](https://github.com/Javis603/token-monitor/commit/148bb9fa995d627b85875e9725139c2fd454202c), including upstream 0.91.0 and the subsequent fixes and features.

<!-- app-update-notes:en:start -->
### Added
- Search the session list directly from the total panel, with the current source and period filters preserved.
- Refresh an individual quota account for supported providers, with account-scoped progress and cooldown feedback.
- Automatically update plugins from trusted sources; menu and settings enable controls stay in sync.
- More display and subscription currencies, including KRW, with ordered currency selectors.
- Optionally show DeepSeek console Search and Fetch fees separately from balance-derived spend.
### Fixed
- Cursor quota accounts no longer retain removed accounts; quota windows show their period labels.
- Settings copy names the current operating system, and language selectors use native language names.
- Hub uploads accept up to 2 MiB. The Worker rejects device records that would exceed its storage-size limit.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 新增
- 从总量面板直接搜索会话列表，保留当前来源与周期筛选。
- 支持单独刷新受支持的额度账户，并显示对应账户的进度及冷却状态。
- 可信来源插件支持自动更新，菜单与设置中的启用开关保持同步。
- 扩展显示和订阅币种，包含韩元，并统一币种选择器排序。
- 可选展示 DeepSeek 控制台 Search / Fetch 费用，与余额变化推导的消费分开显示。
### 修复
- Cursor 不再保留已移除的额度账户，额度窗口补全周期标签。
- 设置文案只显示当前操作系统名称，语言选择器使用各语言自身的名称。
- Hub 上传上限提高至 2 MiB；Worker 对超过存储大小限制的设备记录返回明确错误。
<!-- app-update-notes:zh:end -->

保留此分支的 Antigravity / Codex 在线按需对话查询、默认开启的桌面对话查询开关，以及 Antigravity 用户正文与附加上下文分离显示。对话正文不随常规统计采集、上传或持久化；手机使用原有查询协议。

应用更新源保持为 `AoXIUy/token-monitor`。发布配置继续提供 Windows x64 安装版 / 便携版、Linux amd64 DEB 和 x86_64 AppImage；Windows 沿用已选择的未签名方式。此次合并没有增加 npm 依赖或构建工具。
