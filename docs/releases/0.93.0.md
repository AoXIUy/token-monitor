# Token Monitor 0.93.0

<!-- app-update-notes:en:start -->
### Added
- Optional read-only approval alerts for Codex (`PermissionRequest`) and Antigravity (`PreToolUse`) when a session pauses for confirmation.
- Non-blocking desktop hooks forward confirmation alerts over a permission-restricted local IPC bridge (`approval-bridge.json`, `0600`) to the Node Hub (`POST /api/approval-alerts` / `GET /api/approval-alerts`), then immediately return the native desktop prompt behavior.
- Desktop Multi-Device Sync settings add toggles and one-click hook installation for Codex and Antigravity (including configurable Antigravity `PreToolUse` matcher, defaulting to `run_command`); headless Agent and standalone Node Hub expose `--approval-alerts` / `TOKEN_MONITOR_APPROVAL_ALERTS=1`.
### Notes
- Alerts are read-only and disabled by default across Hub, collector, and Android; confirmations always stay on the desktop. Node Hub keeps alerts in memory only for 2 minutes (max 32 globally / 8 per device); Cloudflare Worker does not implement this route.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 新增
- 新增可选的 Codex（`PermissionRequest`）与 Antigravity（`PreToolUse`）只读审批提醒，在会话暂停等待确认时通知手机端。
- 非阻塞桌面端 Hook 通过受权限保护的本地 IPC 桥（`approval-bridge.json`，`0600`）将待确认提醒发送至 Node Hub（`POST /api/approval-alerts` / `GET /api/approval-alerts`），并立即返回桌面端原生确认流程。
- 桌面端「设置 → 多设备同步」新增总开关与 Codex / Antigravity Hook 一键安装（支持自定义 Antigravity `PreToolUse` 匹配规则，默认 `run_command`）；独立 Hub 与 Agent 支持 `--approval-alerts` / `TOKEN_MONITOR_APPROVAL_ALERTS=1`。
### 说明
- 审批提醒为严格只读且默认全部关闭，所有允许或拒绝操作仍在电脑端完成；Node Hub 仅在内存中保留 2 分钟（全局上限 32 条 / 单设备上限 8 条），Cloudflare Worker 不实现此接口。
<!-- app-update-notes:zh:end -->
