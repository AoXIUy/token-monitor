# Token Monitor 0.98.1

# English

## What's changed

<!-- app-update-notes:en:start -->
### Added
- **OpenClaw Real-Time Event Pushes:** Automatically push sanitized OpenClaw/WeChat notifications on session turn completion (idle settle debounce, subagent & background-review filtering, optional session-title toggle), pending Codex/Antigravity approvals, quota low/recovery warnings, AI service incidents, period rollovers, and manual digests (`POST /api/integrations/openclaw/push`, `GET /api/integrations/openclaw/history`).
- **Expanded Unified Query Layer, Hub Endpoints & MCP Surface:** Added privacy-gated query helpers (`src/shared/openclawQueries.js`) and Hub HTTP routes (`GET /api/query/usage`, `/sessions`, `/history`, `/devices`, `/limits`, `/subscriptions`, `/live-rate`), expanding MCP (`src/shared/mcpReportProtocol.js` and `src/mcp/server.js`) to 17 tools, 9 static resources, 1 template, and 8 prompts with `--local` stdio parity.
- **Desktop `local` Mode OpenClaw Integration & Loopback Bridge:** Unlocked OpenClaw settings persistence, test pushes, and real-time event monitoring in `local` mode (`src/electron/openclawBridge.js`), with an optional loopback-only (`127.0.0.1`) HTTP/MCP bridge backed by `CredentialStore`-isolated Bearer tokens, one-click configuration copy, and token rotation.
- **OpenClaw Skill CLI & Renderer Controls:** Extended `skills/openclaw-token-monitor/` (`usage`, `sessions`, `session-detail`, `history`, `devices`, `limits`, `subscriptions`, `live-rate`, `service-status`, `approvals`, `push`, `push-history`, `--format text/json`) and added Desktop event toggles, completion filters, permission toggles, recent push history, and quick-push actions across the main view and session details.

### Improved
- **Desktop Context Enrichment & Hardening:** Desktop runtime injects local SQLite quota history, live session activity/throughput, and approval status across `local` and `host` modes, with idempotency deduplication, in-flight dispatch coalescing, email/secret redaction, and prototype-safe aggregation.

### Fixed
- **MCP Stdio Startup Compatibility:** Lazy-loaded SQLite-backed session detail and conversation readers in `src/mcp/server.js` so Node 22 MCP stdio startup stays clean without emitting experimental SQLite stderr warnings.
<!-- app-update-notes:en:end -->

# 中文

## 更新内容

<!-- app-update-notes:zh:start -->
### 新增
- **OpenClaw 实时事件主动推送：** 支持会话轮次结束自动推送（含消抖稳定等待、子智能体/后台审查过滤与会话标题脱敏开关）、Codex / Antigravity 待处理审批提醒、额度低水位/恢复告警、AI 服务异常通告以及周期归档/手动简报（`POST /api/integrations/openclaw/push`、`GET /api/integrations/openclaw/history`）。
- **扩展统一查询层、Hub 接口与 MCP 工具集：** 新增受权限控制的统一查询引擎（`src/shared/openclawQueries.js`）与 `/api/query/*` 接口（`usage`、`sessions`、`history`、`devices`、`limits`、`subscriptions`、`live-rate`），将 MCP 扩展至 17 个工具、9 个静态资源、1 个资源模板与 8 个提示词，并支持 `--local` 本地模式全量对齐。
- **桌面端 `local` 模式完整联动与本机回环桥接：** 在单机 `local` 模式下直接支持 OpenClaw 配置保存、测试推送与事件监听（`src/electron/openclawBridge.js`），并提供可选的仅限本机 `127.0.0.1` HTTP/MCP 桥接服务（Bearer 密钥隔离保存于 `CredentialStore`，支持一键复制配置与重置密钥）。
- **OpenClaw Skill CLI 与桌面端交互控件：** 扩展 `skills/openclaw-token-monitor/` 查询与推送子命令（`usage`、`sessions`、`session-detail`、`history`、`devices`、`limits`、`subscriptions`、`live-rate`、`service-status`、`approvals`、`push`、`push-history`，支持 `--format text/json`），并在设置、主界面与会话详情加入事件矩阵、过滤条件、推送历史与快捷推送按钮。

### 改进
- **桌面上下文注入与可靠性加固：** 桌面端在 `local` 与 `host` 模式下统一注入本地 SQLite 额度历史、实时会话吞吐率与审批状态，并实现幂等去重、并发派遣合并、密钥与邮箱脱敏及防原型污染聚合。

### 修复
- **MCP Stdio 启动兼容性：** 在 `src/mcp/server.js` 中改为按需延迟加载依赖 SQLite 的会话详情/对话读取器，避免 Node 22 下 MCP stdio 启动阶段向 `stderr` 输出实验性 SQLite 警告。
<!-- app-update-notes:zh:end -->
