# Token Monitor 0.102.1

# English

## What's changed

<!-- app-update-notes:en:start -->
### Improved
- **Footer Quick Entry for Antigravity Account Manager:** Added a monochrome accounts icon button beside Settings in the main widget footer (`#footerAgManagerButton`) to open the standalone Antigravity Account Manager window in one click, with native liquid-glass styling and 7-language labels.
- **High-Density 4-Column Account Cards:** Redesigned the standalone Antigravity Account Manager window (`1160×740` default size) with compact 4-column glass cards, sky-blue active highlighting, single-line email headers with copy/two-step delete controls, localized active client slot / tier / device fingerprint / inferred capability pills + timestamp, 2-column slim `3px` quota progress grids (`5h` & weekly + full-width dedicated pools), and a 2×2 action grid (`Switch` / `Refresh` / `Enable-Disable` / `More` inline menu).

### Fixed
- **Manager Header Badge Copy:** Fixed the top window header badge to display the standalone-window separation label (`agManager.independentBadge`) instead of the isolated device-fingerprint label.
<!-- app-update-notes:en:end -->

# 中文

## 更新内容

<!-- app-update-notes:zh:start -->
### 改进
- **首页底部快速入口：** 在主窗口底部设置按钮旁新增 Antigravity 账号管理单色图标按钮（`#footerAgManagerButton`），支持一键打开独立账号管理窗口，并适配 Liquid Glass 样式与 7 语言文案。
- **4 列高密度账号卡片改版：** 将独立账号管理窗口默认尺寸调整为 `1160×740`，卡片重构为 4 列自适应深色玻璃布局，支持天蓝色激活边框高亮、邮箱一键复制与两段式删除按钮、本地化客户端槽位/等级/独立指纹/模型能力标签与时间戳、双栏 `3px` 细配额进度网格（5h 与周配额 + 专属池整行展示），以及 `2×2` 操作网格与“更多”内联菜单。

### 修复
- **顶部独立窗口徽章文案：** 修复管理窗口标题栏误显示“已绑定独立指纹”的问题，改为准确展示“独立窗口 · 与主采集完全隔离”标识。
