# Token Monitor 0.92.0

<!-- app-update-notes:en:start -->
### Added
- Antigravity / Codex session details show observed output tok/s, tok/min and a five-minute rate trend on desktop and Android.
- Rates use new output tokens divided by source-device sampling time, independently for each device copy. Duplicate and late snapshots do not generate points; missing data is unavailable and offline intervals remain gaps.
### Notes
- Monitoring begins when details open. Completion-only logs produce batched observations, not per-token streaming. Lifetime matched timing is never used as a realtime rate.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 新增
- 安卓与桌面 Antigravity / Codex 会话详情增加实时输出 tok/s、tok/min 与最近五分钟速率趋势。
- 按来源设备输出计数增量除以来源采样时间差计算，多设备副本分别观测；重复或迟到快照不增加点，缺失数据保持不可用，离线区间留空。
### 说明
- 打开详情后开始监控。只在回复结束时写入的日志会形成批量观测，不代表逐 Token 流速；新实时读数不使用累计匹配均速。
