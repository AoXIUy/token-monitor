# Token Monitor 0.91.2

<!-- app-update-notes:en:start -->
### Fixed
- Antigravity user messages show the actual request, including slash commands, instead of the surrounding export envelope.
- Additional metadata and settings changes remain available as separate collapsible context. Literal, unknown or incomplete wrappers remain intact; assistant and tool messages are unaffected.
- Antigravity pagination cursors now account for the parser format so upgrading cannot silently skip or duplicate fragments.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 修复
- Antigravity 用户消息提取实际发送的正文，例如 `/plan 优化升级总览首页UI UX`，不再把导出的包装标签、命令说明和设置变更混入用户消息。
- 附加元数据和设置变更作为独立上下文保留，手机默认折叠显示。普通文本、未识别或不完整包装、助手及工具原文保持完整。
- 解析格式升级会使旧 Antigravity 分页游标失效，刷新后重新读取，避免继续分页时跳过或重复内容。
<!-- app-update-notes:zh:end -->

此次修复位于来源设备的读取端，更新提供会话的桌面设备后，手机刷新会话即可读取修复后的内容，无需更新 APK。正文仍按需读取，不随普通统计上传或保存。详见[对话查询说明](https://github.com/AoXIUy/token-monitor/blob/v0.91.2/docs/session-conversations.md)。无新增依赖或构建工具。
