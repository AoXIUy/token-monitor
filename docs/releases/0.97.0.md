# Token Monitor 0.97.0

## English

### Added
- **Third-Party AI API Report & Data Analysis:** Configure OpenAI-compatible (DeepSeek, OpenAI, SiliconFlow, New API, OpenRouter, Ollama) or Anthropic Messages APIs in Main Hub / Desktop Host Settings (`PUT /api/reports/integrations`, `POST /api/reports/ai-analyze`) to summarize daily, weekly, and monthly reports along with live device usage and sanitized third-party API / provider quotas.
- **Bidirectional OpenClaw WeChat Integration:** Push formatted WeChat report digests (`openclaw-agent` `/hooks/agent`, `openclaw-wake` `/hooks/wake`, or generic webhook) automatically on period rollover or on demand (`POST /api/reports/push`), and query reports, live stats, and third-party balances from WeChat using the bundled OpenClaw Skill (`skills/openclaw-token-monitor/`) or new MCP tools (`get_realtime_usage_and_limits`, `analyze_report_with_ai`, `push_report_to_openclaw`, and `wechat-digest` prompt).
- **Desktop Integration Controls & Secret Isolation:** Added Third-Party AI and OpenClaw WeChat settings panels in Desktop settings while isolating raw API keys and hook tokens in `userData/credentials.json` (`0o600` private Hub secrets for standalone Hub).

## 中文

### 新增
- **第三方 AI API 报告与数据智能分析：** 在主 Hub 与桌面端设置中接入 OpenAI 兼容接口（DeepSeek、OpenAI、SiliconFlow、New API、OpenRouter、Ollama 等）或 Anthropic Messages API（`PUT /api/reports/integrations`、`POST /api/reports/ai-analyze`），结合周期报告、实时用量及脱敏后的第三方 API / 订阅额度快照自动生成并缓存 AI 分析总结。
- **OpenClaw 微信双向接入：** 支持在周期归档时或手动一键通过 OpenClaw Gateway Webhook（`/hooks/agent` → `openclaw-weixin`、`/hooks/wake` 或通用 Webhook）向微信主动推送报告与余额简报（`POST /api/reports/push`）；同时提供即用型 OpenClaw Skill（`skills/openclaw-token-monitor/`）与新增 MCP 工具（`get_realtime_usage_and_limits`、`analyze_report_with_ai`、`push_report_to_openclaw`、`wechat-digest`）供微信内随时对话查询。
- **桌面端设置与密钥隔离存储：** 桌面端报告设置区新增第三方 AI 与 OpenClaw 微信配置及即时测试按钮；API 密钥与 Hook Token 严格隔离保存在本机 `credentials.json` 或 Hub 私有文件（`0o600`），不向渲染层与只读客户端明文暴露。
