# Token Monitor 0.97.2

## English

### Fixed
- **Desktop Third-Party AI Save & Run Flow:** Fixed renderer dirty-state clobbering before save/analyze, Main/Hub `settings:push` update ordering, secret clearing persistence across restarts, Windows proxy/system-CA routing via `electronLimitsFetch()`, and reasoning-model (`deepseek-flash`) token-budget handling (`maxTokens` default raised to `4096` with automatic single retry and explicit `ai_token_limit` diagnostics).
- **Desktop Integration Controls & Validation:** Styled the Third-Party AI and OpenClaw enable toggles consistently, added pre-save URL/model validation, added one-click Host Hub activation from `local` mode, and localized `ai_*` / `openclaw_*` / `not_found` error feedback across all bundled languages.

### Added
- **OpenClaw WeChat Direct QR Login & Provisioning:** Added zero-dependency CSP-safe SVG QR rendering and `@tencent-weixin/openclaw-weixin` iLink QR login (`wait`, `scaned`, `need_verifycode`, `expired`, `confirmed`) directly in Desktop Settings and Main Hub (`/api/integrations/openclaw/*`), automatically persisting `~/.openclaw/openclaw-weixin/` credentials, configuring the `:18789/hooks/agent` endpoint and `ilink_user_id` target, and provisioning local OpenClaw hooks/skill when available.

## 中文

### 修复
- **桌面端第三方 AI 报告保存与运行问题：** 修复点击保存/分析前渲染层反手清空未保存表单、`settings:push` 与嵌入式 Hub 更新时序倒挂、清除密钥后重启复活、Windows 代理与系统根证书未接入 `electronLimitsFetch()`，以及 `deepseek-flash` 等推理模型在 `maxTokens: 1500` 下耗尽输出预算的问题（默认提升至 `4096` 并支持自动扩充重试与 `ai_token_limit` 明确提示）。
- **桌面端集成开关与校验体验：** 统一第三方 AI 与 OpenClaw 启用开关样式，增加保存前 URL/模型校验、`local` 模式下的一键开启主 Hub 按钮，以及全语言 `ai_*` / `openclaw_*` / `not_found` 错误本地化提示。

### 新增
- **OpenClaw 微信直接扫码接入与自动配置：** 内置零依赖纯 JS SVG 二维码与 `@tencent-weixin/openclaw-weixin` iLink 扫码登录（支持等待扫码、已扫码确认、验证码校验、过期刷新与自动绑定），支持直接写入 `~/.openclaw/openclaw-weixin/` 凭证、自动回填 `:18789/hooks/agent` 与 `ilink_user_id` 接收目标，并在检测到本机 OpenClaw 时一键配置 Hooks 与 `openclaw-token-monitor` 技能。
