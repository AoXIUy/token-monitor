# Token Monitor 0.91.1

<!-- app-update-notes:en:start -->
### Fixed
- Publish Linux x86_64 AppImage alongside the existing Debian and Windows packages, with a shared Linux update feed.
- Multi-device Sync settings now expose a conversation query switch, enabled by default, for Antigravity and Codex conversations and context.
- Switching off immediately revokes pending Hub queries and stops this device serving conversations. Switching back on works without restarting; saved off preferences survive relaunches and environment opt-ins.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 修复
- 正式发布增加 Linux x86_64 AppImage，保留 Debian 和 Windows 包；Linux 两种格式使用合并更新索引。
- 在「设置 → 多设备同步」增加「会话对话查询」开关，默认开启，支持在线设备的 Antigravity 和 Codex 正文及上下文。
- 关闭立即停止本机提供正文；作为 Host 时同时取消未完成查询并关闭 Hub 查询入口。重新开启无需重启，已保存的关闭选择不会被启动环境变量覆盖。
<!-- app-update-notes:zh:end -->

对话仍由客户端按需查询，不随普通统计采集、上传或保存。仅持有共享密钥的客户端可请求已上报会话。桌面 Host / Client 使用本机设置；独立 Node Hub / Agent 继续默认关闭，Cloudflare Worker 不提供此功能。详见[对话查询说明](https://github.com/AoXIUy/token-monitor/blob/v0.91.1/docs/session-conversations.md)。

AppImage 下载后执行 `chmod +x Token-Monitor-0.91.1-x86_64.AppImage` 再运行；Debian 包使用 `sudo apt install ./Token-Monitor-0.91.1-amd64.deb` 安装。AppImage 与 Windows 安装版支持应用内更新，便携版和 .deb 通过“查看 release”下载更新；更新源均为本仓库。

Windows 包按维护者选择保持**未签名**，可能提示“未知发布者”。Actions 完整校验后构建上述四种附件，并生成 `SHA256SUMS` 和源码元数据；完整上传草稿后才公开。两种 Linux 格式独立构建并合并更新索引，保留各自包类型和校验和。无新增依赖或构建工具。
