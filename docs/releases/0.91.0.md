# Token Monitor 0.91.0

<!-- app-update-notes:en:start -->
### Added
- Android can request Antigravity and Codex conversation text from an online device through the Node Hub. Reads happen only when requested; ordinary collection never uploads transcript bodies.
- Conversation pages preserve questions, replies, recorded context and tool input/output, including long text split into continuation fragments.
### Changed
- This fork's desktop updater and release artifacts use AoXIUy/token-monitor.
- Release builds verify Node 22/24, then package unsigned Windows x64 installer / portable executables and a Linux amd64 Debian package. macOS and AppImage artifacts are not published.
<!-- app-update-notes:en:end -->

<!-- app-update-notes:zh:start -->
### 新增
- 配合 Android 1.8.0，可按需查看在线设备的 Antigravity / ChatGPT Codex 会话正文、上下文与工具记录。APK 点击查看时，来源端才读取对应日志，Hub 只在内存中转发当前页。
- 支持分页、长消息续文、压缩 / 归档 Codex rollout、Antigravity IDE / CLI 和 CC Switch 私有导出目录。日志更新、设备离线、缺少正文、超时均有明确结果。
### 调整
- 桌面应用更新源切换到此 fork，避免升级回上游构建。
- 发布前运行 Node 22 / 24 完整校验；仅提供 Windows x64 安装版 / 便携版和 Linux amd64 .deb，并生成 SHA256SUMS 与源码元数据。
<!-- app-update-notes:zh:end -->

对话功能默认关闭。请在 **Node Hub 和每台允许查询的常驻采集端 / 桌面应用** 上分别设置 `TOKEN_MONITOR_SESSION_CONVERSATIONS=1` 后重启。需要 shared secret；持有该 secret 的客户端可查询已上报会话。Cloudflare Worker、一次性 Agent 不提供此扩展。只有二进制 Antigravity 数据或 Dots 计数而没有导出正文时不会补造内容。

完整设置、来源限制和数据边界见[部署说明](https://github.com/AoXIUy/token-monitor/blob/v0.91.0/docs/session-conversations.md)。没有新增 npm 依赖或构建工具；解析使用现有 Node APIs，并参考 [CC Switch](https://github.com/farion1231/cc-switch) 的本地会话格式。

Windows 附件按维护者选择以**未签名**方式发布，可能显示“未知发布者”提示；没有配置或使用上游的 SignPath 签名身份。Windows 安装版支持应用内更新；便携版和 Linux .deb 通过“查看 release”下载并安装更新，更新检查均使用本仓库。

下载：

- [Windows x64 安装版](https://github.com/AoXIUy/token-monitor/releases/download/v0.91.0/Token-Monitor-Setup-0.91.0.exe)
- [Windows x64 便携版](https://github.com/AoXIUy/token-monitor/releases/download/v0.91.0/Token-Monitor-0.91.0.exe)

附件在全部校验和构建通过后上传至草稿，确认完整后公开。`SHA256SUMS` 校验下载完整性；它不替代代码签名。
