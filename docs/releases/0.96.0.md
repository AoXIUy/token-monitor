# Token Monitor 0.96.0

## English

### Added
- **Daily, Weekly, and Monthly Usage & Project Analysis Reports:** Added a shared `token-monitor-report/v1` report engine (`src/shared/usageReport.js`) with calendar-aligned daily (`YYYY-MM-DD`), ISO weekly (`YYYY-Www`), and monthly (`YYYY-MM`) aggregation, period-over-period comparisons, project/tool/model/device breakdowns, automated signals, and standardized Markdown + JSON templates.
- **Main Hub Report Generation & Persistence:** Added `src/hub/reports.js` and authenticated Node Hub routes (`GET /api/reports`, `GET/PUT /api/reports/config`, `GET /api/reports/:granularity/:periodKey`, `POST /api/reports/generate`) with 400-day daily project snapshots (`daily-snapshots.json`), automatic period-rollover archiving, and content-signature deduplication.
- **MCP Report Analysis Integration:** Added zero-dependency MCP JSON-RPC 2.0 support via both Main Hub (`POST /api/mcp`) and standalone stdio server (`npm run mcp` / `src/mcp/server.js`, supporting Hub HTTP API and local direct modes), exposing `list_usage_reports`, `get_usage_report`, `generate_usage_report`, `analyze_project_usage`, report resources (`report://latest/{daily,weekly,monthly}`), and analysis prompts.
- **Desktop Settings Controls:** Added report enablement, daily/weekly/monthly selection, output directory picker, and manual generation controls in Desktop settings synced with Host mode.

### Notes
- See [docs/reports-mcp.md](../reports-mcp.md) and [docs/API.md](../API.md) for API contracts, standard template specifications, and Claude Code / Cursor / Antigravity MCP configuration examples.

## 中文

### 新增
- **按天 / 按周 / 按月数据使用与项目分析报告：** 新增共享报告引擎（`src/shared/usageReport.js`），制定标准 JSON Schema（`token-monitor-report/v1`）与 5 章节 Markdown 报告模板，支持自然日（`YYYY-MM-DD`）、ISO 自然周（`YYYY-Www`）和自然月（`YYYY-MM`）的环比对比、项目/工具/模型/设备拆解与关键特征信号提取。
- **主 Hub 统一生成与持久化：** 新增 `src/hub/reports.js` 与 Node Hub 鉴权接口（`GET /api/reports`、`GET/PUT /api/reports/config`、`GET /api/reports/:granularity/:periodKey`、`POST /api/reports/generate`），维护最近 400 天逐日项目快照（`daily-snapshots.json`），支持自动跨周期归档落盘与内容指纹去重。
- **MCP 分析报告接入：** 提供零外部依赖的 MCP JSON-RPC 2.0 协议支持，同时支持主 Hub Streamable HTTP（`POST /api/mcp`）与独立 stdio 服务（`npm run mcp` / `src/mcp/server.js`，支持连接 Hub 与本地直读两种模式），暴露分析 Tools、Resources 与标准分析 Prompts。
- **桌面端报告设置联动：** 在桌面端设置面板新增按天/按周/按月开关、输出目录选择与立即生成入口，并与 Host 模式嵌入式 Hub 实时同步。

### 说明
- 接口契约、标准模板格式及 Claude Code / Cursor / Antigravity MCP 接入示例见 [docs/reports-mcp.md](../reports-mcp.md) 与 [docs/API.md](../API.md)。
