### Fixed
- **Antigravity RPC Daemon Discovery & Quota Mapping** — Support tokenless Antigravity `2.31+` / `2.33` / `2.34` language servers via `<root>/daemon/*.json` PID matching without blocking on `lsof`, and map newer Gemini 4 quota models without `pro`/`flash`/`argon` suffixes into the `Gemini Pro` quota pool.
- **Antigravity Live Session Activity & Completion** — Add a shared Antigravity session activity provider (`src/shared/providers/antigravity/sessionActivity.js`), extract `turnEnded` state cleanly from `conversation_summaries.db` (`RUNNING`/`BUSY`/`CANCELING`/`not_fully_idle` vs `IDLE`/`killed`), and preserve activity timestamps across catalog refreshes.
- **Antigravity Self-Sync Diagnostics** — Drain `tokscale` child stdout safely and log actionable diagnostics when `tokscale antigravity sync` exits `0` with export candidates present but zero cached sessions produced.

### 修复
- **Antigravity 额度与守护进程探测修复**：支持 Antigravity `2.31+` / `2.33` / `2.34` 的无 token 语言服务探测（通过 `<root>/daemon/*.json` 按存活 PID 关联 HTTPS/HTTP 端口，不再卡在 `lsof` 无 token 过滤），并将不带 `pro`/`flash`/`argon` 后缀的新一代 Gemini 4 模型归入 `Gemini Pro` 额度池。
- **Antigravity 实时会话状态与完成检测**：新增 Antigravity 实时会话活动状态提供器（`src/shared/providers/antigravity/sessionActivity.js`），基于 `conversation_summaries.db` 正确提取 `turnEnded`（区分运行中与已完成状态）并在 catalog 刷新时保留准确的活动时间戳。
- **Antigravity 同步诊断增强**：安全排空 `tokscale` 子进程标准输出，并在存在导出候选但 `tokscale antigravity sync` 同步结果为空时输出诊断日志以便排查。
